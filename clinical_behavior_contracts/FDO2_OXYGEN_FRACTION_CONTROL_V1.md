# Clinical Behavior Contract — ECMO FdO2 Oxygen-Fraction Control v1

**Contract ID:** `cbc.ecmo.fdo2-oxygen-fraction-control.v1`  
**Automation status:** implemented and regression-tested  
**Clinical review status:** expert review pending

## Purpose

Protect the learner-facing distinction between **ECMO gas oxygen fraction (FdO2)** and **sweep-gas flow** without conflating either control with blood-side flow or oxygenator obstruction.

The oxygenator is modeled as receiving a blended gas stream. With sweep flow held nonzero and fixed, changing FdO2 should change the modeled oxygen-transfer state while leaving CO2 clearance and hydraulics materially unchanged.

CBC08 also closes an internal-coherence defect discovered during contract probing: post-oxygenator saturation and pO2 were previously generated by independent approximations and could describe contradictory oxygen states.

## Preconditions

- Pump: 2200 RPM.
- Sweep: 600 mL/min and held constant.
- Bridge closed (`bridge_clamp_position = 0.0`).
- Representative membrane inlet saturation: 0.65.
- Representative membrane inlet pCO2: 58 mmHg.
- FdO2 graded probe: 1.00, 0.80, 0.60, 0.40, 0.21.

These are regression fixtures, not treatment targets.

## Required response

As FdO2 is reduced while sweep and blood-side conditions are held fixed:

1. post-oxygenator pO2 must decrease monotonically;
2. post-oxygenator saturation must remain mathematically coherent with that same modeled pO2;
3. post-oxygenator pCO2 must remain materially unchanged;
4. solved blood/circuit flow must remain materially unchanged.

The control therefore must not behave as a hidden pump-speed, sweep, or blood-path resistance input.

## Coherence repair

Before CBC08, `outlet_o2_saturation()` and `outlet_po2_mmhg()` represented two separate reduced-order transfer approximations. At intermediate FdO2, the simulator could report an unchanged venous-like saturation while simultaneously reporting a highly oxygenated pO2.

CBC08 makes `outlet_po2_mmhg()` the single reduced-order oxygen-transfer state and derives saturation from that pO2 using the inverse of the model's existing Hill relationship. This is an internal-consistency repair; it does not convert the provisional oxygenator model into a device-specific transfer model.

## Restoration branch

Return FdO2 to 1.00.

The membrane-boundary outputs must return to the original result. This is a deterministic re-evaluation of immutable controls, **not** proof of recovery from a persistent blender or oxygen-source fault state.

If a mutable gas-source/blender fault is introduced later, this restoration branch must be replaced or supplemented by a same-runtime activation/clear test.

## Coupled-patient boundary

Phase 10b closes the former coupling block without adding a second oxygen solver. The patient→ECMO adapter now consumes the immutable Phase 9a native mixed-venous oxygen state as the membrane inlet. The existing oxygenator return state then enters the existing native+ECMO arterial mixing path.

With sweep, RPM, blood-side conditions, and native patient state held fixed, reducing FdO2 must therefore lower post-oxygenator pO2 and directionally lower the coupled-patient PaO2. The native mixed-venous inlet state itself must not be rewritten by the FdO2 control, and patient-directed ECMO flow must remain materially unchanged. Returning FdO2 to baseline in the same runtime must restore the coupled oxygenation result.

This is a reduced-order educational relationship. It protects direction, separation of control roles, and reversibility; it does not claim a patient-specific magnitude or time course. Differential upper-body/lower-body VA mixing remains outside CBC08 and is reserved for Phase 11.

## Not modeled

- Persistent blender or oxygen-source fault state.
- Oxygen source depletion/wall-gas failure.
- Gas-line disconnection observations beyond the resulting effective control state.
- Device-specific oxygen-transfer curves.
- Patient-specific quantitative FdO2→PaO2 response magnitude or time course.
- Differential upper-body/lower-body oxygenation or mixing-point migration (Phase 11).

## Validation boundary

A passing CBC08 means the simulator preserves the intended **directional and internal-consistency relationship** between FdO2, true native mixed-venous inlet oxygen, membrane oxygen transfer, mixed coupled-patient arterial oxygenation, CO2 transfer, and hydraulics. It does not clinically validate exact post-oxygenator or patient PaO2 values, a device-specific transfer curve, or any FdO2 prescription.
