# Lung NorthStar Regression Bench v1

This bench is independent of the cardiovascular NorthStar bench.

Frozen standalone cases:
- baseline spontaneous breathing
- reduced compliance
- increased airway resistance
- tachypnea
- reduced respiratory effort
- PEEP 5 cmH2O

The lung module must pass its standalone bench before any cardiopulmonary coupling is enabled.
Gas exchange is intentionally absent in v0.6.0.
