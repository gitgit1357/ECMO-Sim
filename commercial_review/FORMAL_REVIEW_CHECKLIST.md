# Formal Commercial / Regulatory / IP Review Checklist

## Regulatory reviewer
- [ ] Confirm final intended use and intended users.
- [ ] Review all public/product labeling for unintended clinical claims.
- [ ] Determine whether any software function is a device function or otherwise subject to FDA oversight.
- [ ] Determine whether future real-patient-data or real-device integration changes the analysis.
- [ ] Determine any applicable software lifecycle, human-factors, cybersecurity, quality-system, registration/listing, or submission obligations.
- [ ] Record reviewer name, credentials/role, date, scope, sources, and written disposition.

## IP/legal reviewer
- [ ] Inventory project-owned code/content and authorship/assignment records.
- [ ] Review third-party dependency licenses and redistribution obligations.
- [ ] Review all distributable visual/audio/content assets for license/provenance.
- [ ] Perform trademark clearance for final name/logo before commercial branding.
- [ ] Review UI/device-brand similarity for trademark/trade-dress concerns.
- [ ] Decide whether software/documentation copyright registration is desirable.
- [ ] Determine whether a patent/FTO review is commercially warranted.
- [ ] Record reviewer identity, date, scope, and written disposition.

## Facility / deployment reviewer
- [ ] Independent facility ECMO educator clinical review complete.
- [ ] External-training/go-live clinical gate open.
- [ ] Facility simulation/education governance requirements addressed.
- [ ] IT/security/install requirements addressed if deployed on facility systems.
- [ ] Data/privacy review completed if learner records, credentials, network data, or patient-derived data are later introduced.
- [ ] Local device/circuit terminology and policy disclaimers reviewed.

## Release gate
Commercial/external release remains **NOT CLEARED BY THIS CHECKLIST** until the applicable reviewers have completed their own dispositions.
